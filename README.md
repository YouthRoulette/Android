### 김대한
- 룰렛을 돌릴 때마다 화면이 버벅이는 문제가 있어 당황스러웠습니다. 원인을 확인해보니 애니메이션과 화면 렌더링이 동시에 처리되고 있었고, 애니메이션 상태를 별도로 분리해 관리함으로써 훨씬 부드러운 동작을 구현할 수 있었습니다. 버킷 목록 역시 상태 구분이 명확하지 않아 상태값 기준으로 필터링 로직을 추가해 정리했습니다.

### 박민우
- 결과 화면에서 완료·미완료 탭을 전환할 때마다 데이터가 뒤섞이는 문제로 어려움을 겪었습니다. 서버 응답을 하나로 합쳐 처리하는 과정에서 발생한 문제였으며, 상태값을 기준으로 리스트를 분리하여 각각 관리한 결과 각 화면에 정확한 데이터만 표시되도록 개선할 수 있었습니다.

### 이강준
- 로그인 시 앱이 반복적으로 종료되는 문제가 있어 원인 파악에 어려움을 겪었습니다. 확인 결과 서버 주소 형식에 오류가 있었으며, 로그를 단계별로 분석해 원인을 찾아 주소를 수정함으로써 문제를 해결했습니다. 이후 친구 요청이 여러 건일 경우 모두 표시되도록 리스트 형태로 개선하여 마무리했습니다.
